# 🌍 AI Translation Assistant

AI Translation Assistant is an advanced multilingual translation application developed using Python and Gradio. The project uses AI-powered translation techniques to translate text between multiple languages with an interactive and user-friendly interface.

The application automatically detects the source language and translates the text into the selected target language. It also includes emotion detection and voice output features to improve user interaction and accessibility.

The system is integrated with:

* Deep Translator for multilingual translation
* TextBlob for sentiment analysis
* gTTS (Google Text-to-Speech) for voice generation
* Gradio for modern web-based user interface

## 🚀 Main Features

* Multilingual text translation
* Automatic language detection
* Emotion/Sentiment detection
* Voice output for translated text
* Modern AI-based user interface
* Browser-based application
* Real-time translation response

## 🛠 Technologies Used

* Python
* Gradio
* Deep Translator
* TextBlob
* gTTS

## 📌 Working Process

1. User enters text in the input box
2. User selects target language
3. Application detects source language automatically
4. AI translates the text
5. Emotion analysis is performed
6. Voice output is generated
7. Final translated text is displayed on screen
